# Rechtlicher Disclaimer

Dieses Tool bietet eine allgemeine, quellenbasierte Orientierung zum deutschen
Einkommensteuerrecht. **Es ersetzt keine individuelle Steuerberatung.**

Steuerliche Ergebnisse können vom Einzelfall abhängen. Bei

- hohen Beträgen,
- Selbständigkeit,
- Vermietung und Verpachtung,
- Auslandssachverhalten,
- Pflegefällen,
- alten Verlusten / Verlustvorträgen,
- bereits bestandskräftigen Steuerbescheiden oder
- komplexen Ausbildungs-/Studienkosten

sollte ein Steuerberater, eine Steuerberaterin oder ein Lohnsteuerhilfeverein
hinzugezogen werden.

## Charakter der Angaben

- Die im Tool genannten Beträge, Pauschalen und Grenzwerte sind nach bestem
  Wissen recherchiert, aber **ohne Gewähr**. Maßgeblich sind stets die amtlichen
  Werte des jeweiligen Veranlagungsjahres.
- Werte, die noch amtlich zu prüfen sind, werden im Tool als „Wert zu prüfen“
  gekennzeichnet und sind in [`TAX_RULES_TODO.md`](./TAX_RULES_TODO.md)
  aufgeführt.
- Die Berechnungen sind **Schätzungen** und vereinfachen die tatsächliche
  Steuerberechnung (z. B. Progression, Soli, Kirchensteuer, Anrechnungen).

## Datenschutz (Privacy-first)

- Es findet **kein Tracking** statt.
- Eingaben werden ausschließlich **lokal im Browser** (LocalStorage)
  gespeichert und **nicht** an einen Server übertragen.
- Es werden keine sensiblen Steuerdaten serverseitig gespeichert.
